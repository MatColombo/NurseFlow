## Ambiente e correzioni

Node e npm non erano installati nel `PATH` dell'ambiente iniziale. È stato scaricato l'archivio ufficiale Node LTS, verificato con SHA-256 ed estratto sotto `%TEMP%/nurseflow-f00-tools/`, senza installazioni globali o modifica permanente del `PATH`. Per il normale sviluppo occorre installare/usare la versione indicata in `.nvmrc`; i comandi di verifica hanno usato esplicitamente questo runtime portatile.

Il primo download dei browser è fallito con `UNABLE_TO_GET_ISSUER_CERT_LOCALLY`. È riuscito impostando `NODE_USE_SYSTEM_CA=1` solo nel processo di installazione, utilizzando le CA di Windows e mantenendo la verifica TLS. La variabile non è necessaria all'app e non viene incorporata nel repository o nei workflow. Su questa macchina può servire nuovamente per futuri download Playwright.

Il primo typecheck ha rilevato `Navigator.serviceWorker` senza libreria DOM nei test E2E e `workers: undefined` incompatibile con `exactOptionalPropertyTypes`. Entrambi sono stati corretti e i controlli rilanciati con successo. È stato anche rimosso l'avviso Vite relativo all'import di configurazione senza estensione.

Browser scaricati: Chromium 156.0.8078.4 (revision 1248), Firefox 157.0 (1555), WebKit 27.2 (2370). Le esecuzioni sono headless locali, senza dati applicativi reali.

Totale: **29 unit/component/config test e 96 esecuzioni E2E passate**, con mount reale, 13 deep link + reload, recupero hash sconosciuto, nessuna richiesta esterna e nessun service worker. Dopo i test sulla sottocartella viene ripristinata la build locale con la base predefinita `/` per `npm run preview`.
